# LearnHub — Editable Figma UI Kit (SVG)

This package contains nine editable vector screen designs and two rubric evidence boards.

## Import into Figma
1. Open Figma and create a new Design file.
2. Drag the individual `.svg` files onto the canvas, or use File → Place image.
3. For editable elements, right-click an imported SVG and choose **Ungroup** if available. Text and vector shapes are imported as editable layers in Figma; some grouped elements may need to be ungrouped.
4. Set each individual screen frame to 393 × 852 px if you want to rebuild it as a native Figma frame.
5. The two evidence boards are presentation layouts containing the screens at reduced scale. Use them as references; create final evidence exports from your Figma file.
