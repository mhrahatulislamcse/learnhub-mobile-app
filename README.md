**LearnHub** is a production-grade educational and learning resource discovery mobile application developed with Flutter and Firebase. It provides students, researchers, and lifelong learners with instant access to millions of books via the Open Library REST API, real-time Cloud Firestore synchronization, secure Firebase Authentication, offline SharedPreferences persistence, scheduled local study notifications, and complete Material Design 3 theming.

## Application Architecture

LearnHub adopts a **Feature-First Clean Architecture** with **Provider** (`ChangeNotifier`) state management:

```
lib/
├── main.dart                          # Application entry point & service initialization
├── firebase_options.dart              # Firebase project configuration credentials
├── app/
│   ├── app.dart                       # Root MultiProvider and MaterialApp.router setup
│   ├── routes.dart                    # GoRouter route declarations & navigation paths
│   └── theme.dart                     # Light & Dark ThemeData configurations
├── core/
│   ├── constants/                     # AppColors, AppConstants
│   ├── errors/                        # Custom AppExceptions (Auth, Server, Network)
│   ├── theme/                         # Material Design 3 palettes & typography
│   ├── utils/                         # AppLogger, Validators
│   └── widgets/                       # Reusable CustomButton, CustomTextField, LoadingView, AppErrorWidget
├── models/
│   ├── user_model.dart                # User entity with Firestore/JSON serialization
│   └── book_model.dart                # Book entity with Open Library JSON parser
├── features/
│   ├── auth/                          # LoginScreen, RegisterScreen, AuthService, AuthProvider
│   ├── home/                          # HomeScreen, BookCard, SearchBarWidget, CategorySelector
│   ├── details/                       # BookDetailScreen with Hero cover animation & overview
│   ├── favorites/                     # FavoritesScreen, FavoritesProvider with cloud/local sync
│   ├── profile/                       # ProfileScreen with learning statistics & credentials
│   ├── settings/                      # SettingsScreen, SettingsDrawer, SettingsProvider
│   ├── notifications/                 # NotificationScreen, NotificationService, NotificationProvider
│   └── books/                         # ApiIntegrationScreen (REST telemetry), BooksProvider
└── services/
    ├── firebase_service.dart          # Firestore collections & transactions
    ├── api_service.dart               # Open Library HTTP REST Client with telemetry
    └── storage_service.dart           # SharedPreferences local favorites & theme caching
```

## External API Integration (Open Library)

- **API Documentation**: [https://openlibrary.org/developers/api](https://openlibrary.org/developers/api)
- **Search Endpoint**: `https://openlibrary.org/search.json?q={query}&limit={limit}`
- **Covers CDN**: `https://covers.openlibrary.org/b/id/{cover_id}-M.jpg`
- **Telemetry Wrapper** (`ApiResult`): Captures request latency in milliseconds, HTTP status code, total catalog count (`numFound`), and active URL.
- **Defensive Parsing**: Handles varying author fields (`List` vs `String`), null cover IDs with fallback vector icons, and network timeouts with `NetworkException`.

## Local Storage & Persistence

- **Engine**: `shared_preferences`
- **Persisted Elements**:
  - Saved favorite book IDs (`List<String>`)
  - Full serialized favorite book JSON payloads for offline access
  - Selected Theme Mode (`system`, `light`, `dark`)
  - Daily Study Reminder preferences & toggle states
- **Two-Way Synchronization**: Automatically syncs local favorites with Cloud Firestore under `favorites/{uid}/books/{bookId}` when the user is authenticated.

---

## Local Notifications Configuration

- **Library**: `flutter_local_notifications` (v22.3.3) & `timezone`
- **Android Notification Channels**:
  - `learnhub_study_reminders`: High Importance, sound & vibration enabled for daily reminders and instant alerts.
  - `learnhub_book_discovery`: Default Importance for recommendation updates.
- **Scheduled Notifications**: Uses `zonedSchedule` with `AndroidScheduleMode.exactAllowWhileIdle` and `DateTimeComponents.time` for reliable daily recurring study reminders.
- **Android Permissions**: Configured in `AndroidManifest.xml` (`POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED`, `VIBRATE`).

## Security & Data Privacy

- **Firebase Authentication**: User passwords are encrypted at rest and in transit via Firebase Authentication; plain-text passwords are never stored in Firestore or local storage.
- **Firestore Security Rules**: User profiles and favorites are strictly locked to `request.auth.uid == userId`.
- **Zero Sensitive Storage**: `SharedPreferences` caches only non-confidential book metadata, theme settings, and notification switches.
